# フィッシング・ローグ (Fishing Rogue)

[フィッシング・エボリューション](https://github.com/mori618/fishing) をベースにしたローグライト版です。
釣りの操作感・見た目・スキルはそのままに、**限られた餌でラウンドごとの目標額に挑む**ゲームに作り替えています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

## ルール

1. **出航** … 港で2つの海域から1つを選んで出航します。海域ごとに目標額と効果が変わります（穏やかな湾・沖合・嵐の海・宝の入り江・月夜の海・群れの潮）。
2. **餌の支給** … 毎ラウンド餌が10個支給されます。ランクはラウンドが進むと上がります（R1〜3はD、R4〜6はC、R7〜9はB、R10以降はA）。
3. **釣り** … 一投ごとに餌を1つ使います（釣れなくても減ります）。釣った魚はその場で自動売却され、ラウンドの「水揚げ額」に加算されます。続けて釣り上げると売値が+10%ずつ上がります（コンボ、最大+50%）。
4. **目標達成と帰港** … 水揚げ額が目標に届くと「帰港」できるようになります。粘って目標の1.5倍で評価「銀」（報酬4択）、2倍で「金」（報酬4択・Tier1段階上・入れ替え1回無料）。餌が尽きると自動で帰港します。
5. **ゲームオーバー** … 目標に届かないまま、持っている餌がすべて尽きると航海終了です。
6. **港** … 報酬スキルを選び（受け取らずにお金をもらうことも可能）、スキル・上位ランクの餌・竿の強化／買い替えを1画面で購入します。スキルの付け替え・売却は、上部のビルド帯のアイコンから行います。
7. ラウンド10をクリアすると**航海達成**。そのままエンドレスで続けられます。

ゲージバトルでは、相手との力関係（余裕・互角・格上・無謀）と、赤・緑・白それぞれのゾーンで止めたときの捕獲率が表示されます。港の餌には、今のパワーでの釣り上げ成功率の目安が出ます。

買った餌は次のラウンド以降に持ち越せます（余った支給分だけがボーナスに換わります）。スキルスロットは「2 + 竿の購入・星強化の回数」です。

航海をまたいで残るのは**魚図鑑**と**最高記録**だけです。航海の途中経過は自動保存され、タイトルの「つづきから」で再開できます。

## 画面構成

| 画面 | 内容 |
| --- | --- |
| タイトル | 新しい航海／つづきから／魚図鑑、最高記録 |
| 釣り | 上部バー（ラウンド・目標の進み具合・所持金）、パワー・コンボ・海域のチップ、餌スロット、装備確認、帰港ボタン |
| 港 | ビルド帯（竿・パワー・スキル）、ラウンド結果と報酬選択 → スキル・餌・竿のショップ、海域カード（タップで出航） |
| 魚図鑑 | これまでの航海で釣った魚 |

## 原作から変えたところ

- 町・釣具店・スキル店・ガチャ・カジノ・港（船）・合成工房・ミッション・ランク（経験値）・戦績画面を廃止し、買い物と装備は「港」1画面に集約
- 魚の売却は自動（インベントリと売却操作を廃止）
- 餌はすべて有限。Dランクの餌も毎ラウンドの支給分だけ
- スキルは「ラウンド報酬」「港での購入」「宝箱」「称号付きの魚」から入手。Tierはラウンドが進むほど上がる
- ローグライト版で機能しない／バランスを壊すスキル（船・ガチャ・ミッション・経験値関連、ランクスナイパー、無限餌、ハードモードなど）は出現しない
- 竿の価格・強化費用はローグライト用の価格表（`ROGUE_CONFIG.rodPrices` / `rodUpgradeCosts`）
- 強すぎるスキル（闇取引・餌の達人・ダブル／トリプルキャッチ・売値UP 極）は効果を弱めています（`ROGUE_CONFIG.skillOverrides`）
- 宝箱のお金はラウンドの目標額に比例します

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `data/gameData.js` | マスターデータ。**バランス調整は末尾の `ROGUE_CONFIG`**（目標額、支給餌、評価、コンボ、海域、餌の品揃え、竿とスキルの価格、Tier出現率、スキル調整、除外スキル） |
| `js/RunManager.js` | 航海のルール（ラウンド進行、クリア／ゲームオーバー判定、スキル抽選、港での売買） |
| `js/HarborUI.js` | 港画面、装備確認・ゲームオーバーのモーダルの描画 |
| `js/GameState.js` | 航海中のプレイヤー状態と、スキル効果の計算 |
| `js/FishingGame.js` | 釣りの1サイクル（キャスト〜ゲージバトル〜結果） |
| `js/UIManager.js` | 釣り画面の表示・演出 |
| `js/RodAnimator.js` | 竿・糸・ウキ・水面の演出を1枚のSVGに描く。動きの調整値は先頭の `CONFIG` |
| `js/SaveManager.js` | 航海データとメタデータ（図鑑・最高記録）の保存 |
| `js/EncyclopediaManager.js` | 魚図鑑 |
| `styles.css` / `rogue.css` | 原作のスタイル／ローグライト版で追加したスタイル |
| `tools/balance-sim.js` | バランス試算。`node tools/balance-sim.js` で、腕前別に各ラウンドをクリアできる割合を出す |

## バランス調整の手順

`ROGUE_CONFIG` を変えたら `node tools/balance-sim.js` を実行し、到達率が狙いに収まっているかを見ます。いまの狙いは「標準ビルド」の表で、標準の腕前が R5 で約9割・R10 で3〜5割、初心者が R5 で約5割です。宝箱・フィーバー・評価の報酬は試算に入っていないため、実際はこれより少し易しくなります。

`SKILL_LIST.md` と `game_data_csv/` は原作から引き継いだスキル・データの資料です（ローグライト版で出現しないスキルも含みます）。
