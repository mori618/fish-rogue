# フィッシング・ローグ (Fishing Rogue)

[フィッシング・エボリューション](https://github.com/mori618/fishing) をベースにしたローグライト版です。
釣りの操作感・見た目・スキルはそのままに、**限られた餌でラウンドごとの目標額に挑む釣り旅**に作り替えています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部フォントやアイコンの読み込みなし）。

## ルール

1. **竿選び** … 釣り旅の最初に、木の竿を3本（万能竿＋解禁済みからランダム2タイプ）から1本選びます。釣り旅を達成したことがあれば、ここで荒波レベルも選べます。
2. **水域の旅** … 里の水辺（R1〜3）→ 川と湖（R4〜6）→ 沿岸（R7〜9）→ 外洋（R10〜）と進みます。釣り宿では、その水域の3つの釣り場から1つを選んで出発します。
3. **釣り場と天候** … 釣り場ごとによく釣れる魚が違います。天候（晴れ・凪・嵐・お宝日和・月夜・群れ）で目標額と効果が変わり、「本日の高値」の魚は売値が2倍です。
4. **餌の支給** … 毎ラウンド餌が10個支給されます。ランクはラウンドが進むと上がります（R1〜3はD、R4〜6はC、R7〜9はB、R10以降はA）。
5. **釣り** … 一投ごとに餌を1つ使います（釣れなくても減ります）。釣った魚はその場で自動売却され、ラウンドの「水揚げ額」に加算されます。続けて釣り上げると売値が+10%ずつ上がります（コンボ、最大+50%）。
6. **ヌシ戦** … R3・R6・R9・R10 は、目標額に加えてヌシを釣り上げるのが条件です。ヌシは6投目からかかり、ゲージは3連戦で回を追うごとに速くなります。逃げられても勝った連戦の分は残ります。釣ると特別スキルを3択から1つもらえます。
7. **目標達成と宿へ戻る** … 条件を満たすと「宿へ戻る」が出ます。粘って目標の1.5倍で評価「銀」（報酬4択）、2倍で「金」（報酬4択・Tier1段階上・入れ替え1回無料）。餌が尽きると自動で宿へ戻ります。
8. **ゲームオーバー** … 条件を満たさないまま、持っている餌がすべて尽きると釣り旅は終わりです。
9. **釣り宿** … 評価とボーナスを確かめたら、報酬スキルを選び（受け取らずにお金をもらうことも可能）、スキル・餌・特殊餌・竿の強化／買い替えを1画面で購入します。スキルの付け替え・売却は、上部のビルド帯のアイコンから行います。
10. ラウンド10をクリアすると**釣り旅達成**。そのままエンドレスで続けられます。

### 竿のタイプ

竿は「素材（木・竹・カーボン・チタン・伝説）× タイプ」です。タイプは万能竿（値段2割引）・剛竿（パワー+20%、ゲージが速い）・軟竿（赤ゾーンが広い、パワー-15%）・早竿（待ち時間-30%、コンボ上限+2、パワー-10%）・探り竿（宝箱・称号付きが出やすい、売値-10%）の5種類で、形と動きもタイプごとに違います。釣り宿の竿の棚には、次の素材の竿が2タイプ並びます（買えるのは1本）。

### スキルの系統

スキルは剛腕・技巧・商売・宝探し・天体・群れの6系統に分かれ、同じ系統を2つ・4つ装備するとボーナスが付きます（例: 剛腕2つでパワー+15%、4つでパワーが魚の1.5倍以上なら必ず2匹）。剛竿・軟竿・早竿・探り竿は、それぞれ剛腕・技巧・群れ・宝探しの1つ分に数えます。報酬やショップのカードには、取ると発動する系統が表示されます。

### 特殊餌

釣り宿に1種だけ並びます。練り餌（逃げられても減らない、Cランク中心）、まき餌（投げると次の3投の待ち時間が半分・2匹釣り+30%、この餌では釣れない）、光る餌（称号付き10倍・宝箱+10%、ランクは支給餌と同じ）。

### 釣り旅をまたぐ成長

残るのは魚図鑑・最高記録・解禁です。図鑑の登録数や到達ラウンドで、軟竿・早竿・探り竿とまき餌・光る餌が解禁されます（条件はタイトル画面と竿選びに表示）。釣り旅を達成すると、荒波レベル（目標額+15%、支給餌-1、餌の在庫-1、さらに目標額+15%、報酬の選択肢-1 が順に加わる）を選べます。

釣り旅の途中経過は自動保存され、タイトルの「つづきから」で再開できます。効果音はタイトル画面と装備画面で切り替えられます。

## 画面構成

| 画面 | 内容 |
| --- | --- |
| タイトル | 新しい釣り旅／つづきから／魚図鑑、図鑑の登録数・最高記録・前回の結果・次の解禁 |
| 釣り | 上部バー（ラウンド・目標の進み具合）、所持金・パワー・コンボ・ヌシ・天候と釣り場のチップ、餌スロット、装備確認、宿へ戻るボタン |
| 釣り宿 | 到着時の評価メダル、ビルド帯（竿・パワー・スキル・系統）、報酬選択 → スキル・餌・竿のショップ、釣り場カード（タップで出発） |
| 魚図鑑 | これまでの釣り旅で釣った魚と、よく釣れる釣り場 |

最初の釣り旅では、合わせ・ゲージ・釣り宿の使い方を一度ずつ案内します。

## 原作から変えたところ

- 町・釣具店・スキル店・ガチャ・カジノ・港（船）・合成工房・ミッション・ランク（経験値）・戦績画面を廃止し、買い物と装備は「釣り宿」1画面に集約
- 魚の売却は自動（インベントリと売却操作を廃止）
- 餌はすべて有限。Dランクの餌も毎ラウンドの支給分だけ
- スキルは「ラウンド報酬」「ヌシの報酬」「釣り宿での購入」「宝箱」「称号付きの魚」から入手。Tierはラウンドが進むほど上がる
- ローグライト版で機能しない／バランスを壊すスキル（船・ガチャ・ミッション・経験値関連、ランクスナイパー、無限餌、ハードモードなど）は出現しない
- 竿の価格・強化費用はローグライト用の価格表（`ROGUE_CONFIG.rodPrices` / `rodUpgradeCosts`）
- 強すぎるスキル（闇取引・餌の達人・ダブル／トリプルキャッチ・売値UP 極）は効果を弱めています（`ROGUE_CONFIG.skillOverrides`）
- 宝箱のお金はラウンドの目標額に比例します
- 竿の描画を1枚のSVGに作り直し、効果音を追加。アイコンはSVGで同梱

## バランス調整の手順

`ROGUE_CONFIG` を変えたら `node tools/balance-sim.js` を実行し、到達率が狙いに収まっているかを見ます。竿のタイプや荒波レベルを指定するときは `node tools/balance-sim.js 1500 strong 2` のようにします。

いまの狙いは「標準ビルド」の表で、標準の腕前が R5 で約9割・R10 で3〜5割、初心者が R3 で6〜7割です。宝箱・フィーバー・系統ボーナス・特殊餌・評価の報酬は試算に入っていないため、実際はこれより少し易しくなります。

`SKILL_LIST.md` と `game_data_csv/` は原作から引き継いだスキル・データの資料です（ローグライト版で出現しないスキルも含みます）。
