# フィッシング・ローグ (Fishing Rogue)

[フィッシング・エボリューション](https://github.com/mori618/fishing) をベースにしたローグライト版です。
釣りの操作感・見た目・スキルはそのままに、**限られた餌でラウンドごとの目標額に挑む**ゲームに作り替えています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要）。

## ルール

1. **ラウンド開始** … 基本の餌（Dランクの餌）が10個支給されます。
2. **釣り** … 一投ごとに餌を1つ使います（釣れなくても減ります）。釣った魚はその場で自動売却され、ラウンドの「水揚げ額」に加算されます。
3. **ラウンドクリア** … 水揚げ額が目標に届いた時点でクリア。クリアボーナスに加え、余った基本の餌もお金に換わります。
4. **ゲームオーバー** … 目標に届かないまま、持っている餌がすべて尽きると航海終了です。
5. **港** … クリアするたびに港に寄り、次のラウンドに備えます。
   - 報酬スキルを3つの中から1つ選ぶ（受け取らずにお金をもらうことも可能）
   - スキル・上位ランクの餌・竿の強化／買い替えを購入する
   - スキルの付け替え・売却
6. ラウンド10をクリアすると**航海達成**。そのままエンドレスで続けられます。

買った餌（C〜Sランク）は次のラウンド以降に持ち越せます。スキルスロットは「2 + 竿の購入・星強化の回数」です。

航海をまたいで残るのは**魚図鑑**と**最高記録**だけです。航海の途中経過は自動保存され、タイトルの「つづきから」で再開できます。

## 画面構成

| 画面 | 内容 |
| --- | --- |
| タイトル | 新しい航海／つづきから／魚図鑑、最高記録 |
| 釣り | 所持金・パワー・ラウンド目標の進み具合、餌の切り替え、装備確認（閲覧のみ） |
| 港 | 報酬選択 →「ショップ」「装備」の2タブ、次ラウンドの目標と出航ボタン |
| 魚図鑑 | これまでの航海で釣った魚 |

## 原作から変えたところ

- 町・釣具店・スキル店・ガチャ・カジノ・港（船）・合成工房・ミッション・ランク（経験値）・戦績画面を廃止し、買い物と装備は「港」1画面に集約
- 魚の売却は自動（インベントリと売却操作を廃止）
- 餌はすべて有限。Dランクの餌も毎ラウンドの支給分だけ
- スキルは「ラウンド報酬」「港での購入」「宝箱」「称号付きの魚」から入手。Tierはラウンドが進むほど上がる
- ローグライト版で機能しない／バランスを壊すスキル（船・ガチャ・ミッション・経験値関連、ランクスナイパー、無限餌、ハードモードなど）は出現しない
- 竿の価格・強化費用は原作の0.4倍

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `data/gameData.js` | マスターデータ。**バランス調整は末尾の `ROGUE_CONFIG`**（目標額、支給餌数、餌の品揃え、スキル価格、Tier出現率、除外スキル） |
| `js/RunManager.js` | 航海のルール（ラウンド進行、クリア／ゲームオーバー判定、スキル抽選、港での売買） |
| `js/HarborUI.js` | 港画面、装備確認・ゲームオーバーのモーダルの描画 |
| `js/GameState.js` | 航海中のプレイヤー状態と、スキル効果の計算 |
| `js/FishingGame.js` | 釣りの1サイクル（キャスト〜ゲージバトル〜結果） |
| `js/UIManager.js` | 釣り画面の表示・演出 |
| `js/SaveManager.js` | 航海データとメタデータ（図鑑・最高記録）の保存 |
| `js/EncyclopediaManager.js` | 魚図鑑 |
| `styles.css` / `rogue.css` | 原作のスタイル／ローグライト版で追加したスタイル |

`SKILL_LIST.md` と `game_data_csv/` は原作から引き継いだスキル・データの資料です（ローグライト版で出現しないスキルも含みます）。
